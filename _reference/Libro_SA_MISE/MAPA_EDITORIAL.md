# Qué se edita y qué se genera

| Lugar | Función | Edición |
|---|---|---|
| marco_teorico | Relato y explicación | Fuente editable de cada recorrido |
| practica_computacional | Cálculo y discusión | Fuente editable de cada recorrido |
| cuadernos_integrados | Lectura y cálculo en un notebook | Generado por construir.py |
| _build | Libro HTML | Generado por Jupyter Book |
| sa_mise, datos, tests | Implementación, extractos y controles | Fuente común en Libro; copia derivada en Caso |
| entregas | Trabajo de cada equipo | No sobrescribir al actualizar material |

La repetición entre fuentes e integrados es compilación. La repetición de componentes entre libro y caso permite distribución autónoma, pero tiene una sola fuente de mantenimiento. Los ejercicios del caso usan las técnicas para responder preguntas sectoriales adicionales, no repiten solamente la lección intuitiva.
